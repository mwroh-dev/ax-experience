# 배송 지연 시 소비자 권리 가이드

## 개요

전자상거래법 제15조는 사업자가 주문받은 날로부터 일정 기간 내에 재화를 공급해야 할 의무를 규정하고 있습니다. 약정된 배송일을 초과하는 경우, 소비자는 계약 취소 및 손해배상을 청구할 수 있습니다.

---

## 법적 배송 의무 기한

### 전자상거래법 제15조
- 상품 공급: 청약을 받은 날로부터 **3영업일 이내** 출고 또는 공급 시작
- 단, 선불 결제의 경우 대금을 받은 날부터 기산

### 스타일커머스 약정 배송 기준

| 배송 유형 | 약정 기한 |
|----------|----------|
| 일반 배송 | 결제 완료 후 3~5 영업일 이내 도착 |
| 로켓배송 (당일) | 오후 2시 이전 결제 시 당일 도착 |
| 로켓배송 (익일) | 오후 2시 이후 결제 시 익일 도착 |
| 설치 상품 | 결제 후 7~14 영업일 내 배송 및 설치 |
| 예약 배송 | 소비자가 지정한 날짜 |
| 해외 직구 | 결제 후 10~20 영업일 |

---

## 배송 지연 기준

### 지연으로 인정되는 경우
- 약정 배송일 다음 날까지 배송되지 않은 경우
- 배송 예정일이 별도로 표시된 경우 해당 날짜를 초과한 경우
- 배송사 정보가 없는 상태로 출고 예정일 초과

### 지연으로 인정되지 않는 경우
- 천재지변 (태풍, 폭설, 지진) 등 불가항력적 사유
- 소비자 귀책 (잘못된 주소 입력, 부재 시 수령 거부)
- 업체 사전 공지가 있었던 공휴일 기간 배송 지연

---

## 소비자의 권리

### 1. 계약 취소권 (청약철회 기간 경과 후에도 적용)

**행사 조건**: 약정 배송일을 초과한 경우

**행사 방법**:
1. CS 채팅/전화로 배송 지연 사유 확인 요청
2. 배송 불가 또는 상당 기간 지연이 예상되는 경우 취소 의사 표시
3. 취소 접수 후 결제 금액 전액 환불

**주의사항**:
- 배송 중 상태인 경우 반송 처리 후 환불
- 이미 배달 완료된 경우는 취소 불가 (반품으로 전환)

### 2. 배송 지연 보상

스타일커머스 자체 정책에 따른 보상:

| 지연 기간 | 보상 내용 |
|----------|----------|
| 1~2일 지연 | 500 포인트 지급 |
| 3~5일 지연 | 1,000 포인트 지급 |
| 6일 이상 지연 | 2,000 포인트 + 사과 쿠폰 (5%) |
| 배송 불가 (분실) | 전액 환불 + 3,000 포인트 지급 |

**보상 신청**: CS 접수 또는 시스템 자동 지급 (주문 완료 7일 후 미배달 시)

### 3. 법적 손해배상 청구

**민법 제390조**(채무불이행 손해배상): 배송 지연으로 인한 실손해 청구 가능
- 입증 필요: 배송 지연으로 인한 구체적인 손해 발생 사실
- 예: 행사 날짜에 맞추지 못해 발생한 추가 구입 비용

---

## CS 에이전트 처리 절차

### 배송 지연 문의 접수 시

1. **현황 확인**: 운송장 번호 조회, 배송사 시스템 확인
2. **사유 파악**: 배송사 직접 확인 (필요 시)
3. **소비자 안내**: 예상 도착일 또는 사유 안내
4. **취소 요청 시**: 즉시 취소 처리 및 환불 진행
5. **보상 처리**: 지연 보상 포인트 자동 지급 확인

### 에스컬레이션 기준
- 7일 이상 지연 또는 배송 분실이 의심되는 경우
- 소비자가 법적 조치를 예고한 경우
- 동일 지역 다수 소비자 배송 지연 발생 시 (시스템 이슈 의심)

---

## 특수 배송 상황별 처리

### 로켓배송 약속 미이행
- 당일/익일 배송 보장 실패 시 즉시 보상 (자동 쿠폰 발행)
- 소비자가 원하는 경우 즉시 취소 및 전액 환불

### 설치 상품 일정 변경
- 소비자 동의 없는 일방적 일정 변경 금지
- 불가피한 경우 최소 2일 전 사전 통지 및 소비자 확인
- 소비자가 새 일정 거부 시 취소 및 전액 환불

---

## 관련 법령

- 전자상거래 등에서의 소비자보호에 관한 법률 제15조 (재화 등의 공급)
- 전자상거래 등에서의 소비자보호에 관한 법률 제17조 (청약철회 등)
- 민법 제390조 (채무불이행과 손해배상)
