# 스타일커머스 계정 정지 정책

**버전**: v1.5 | **시행일**: 2024년 1월 1일

---

## 1. 계정 정지 개요

스타일커머스는 건전한 거래 환경 보호와 다른 소비자의 권리 보호를 위해, 이용약관 및 본 정책을 위반한 계정에 대해 제재 조치를 취할 수 있습니다. 모든 제재는 단계적으로 이루어지며, 소비자의 이의신청권이 보장됩니다.

---

## 2. 계정 정지 사유

### 2.1 즉시 영구 정지 대상 (1회 위반)

| 위반 유형 | 설명 |
|----------|------|
| 사기 행위 | 허위 반품 신청, 상품 교체 후 반품, 결제 사기 |
| 개인정보 도용 | 타인의 계정/신용카드/개인정보 무단 사용 |
| 비정상 구매 | 상업적 재판매 목적의 대량 구매·반품 반복 |
| 시스템 해킹 | 취약점 공격, 비정상적 API 접근, 크롤링 |
| 직원 사칭 | 스타일커머스 임직원을 사칭한 사기 행위 |

### 2.2 단계적 제재 대상

**1차 경고 → 2차 7일 정지 → 3차 30일 정지 → 4차 영구 정지**

| 위반 유형 | 기준 |
|----------|------|
| 반품 남용 | 12개월 내 반품률 50% 초과 (5회 이상 구매 기준) |
| 허위 리뷰 | 금전적 보상 받은 허위 리뷰, 경쟁사 악의적 평가 |
| 쿠폰 어뷰징 | 복수 계정 생성하여 쿠폰 중복 수령 |
| 악성 CS 행위 | 상담원 폭언, 협박, 반복적 불합리한 요구 |
| 리셀 어뷰징 | 한정판 상품 구매 후 즉시 재판매 반복 (월 5회 이상) |

---

## 3. 반품 남용 판단 기준

반품 정책을 선의로 이용하는 소비자를 보호하기 위해 아래 기준을 적용합니다:

| 구분 | 반품률 | 처리 |
|------|-------|------|
| 정상 | 30% 이하 | 제재 없음 |
| 주의 | 30~50% | 모니터링 + 안내 이메일 발송 |
| 경고 | 50~70% | 1차 경고 + 반품 처리 사전 검토 |
| 제재 | 70% 이상 | CS 팀장 검토 후 계정 제한 |

**반품률 계산**: (반품 건수 / 총 주문 건수) × 100
**최소 기준**: 12개월 내 5건 이상 주문 시 적용

---

## 4. 계정 정지 절차

### 4.1 정지 전 단계

1. **내부 모니터링 감지**: 시스템 이상 패턴 감지
2. **CS 팀 검토**: 담당자가 위반 사항 확인 및 증거 수집
3. **팀장 승인**: 정지 결정 전 팀장급 이상 승인 필수
4. **사전 통보**: 영구 정지 제외한 경우, 정지 전 3영업일 내 이메일 통보

### 4.2 정지 집행

- 정지 결정 시 계정 로그인 차단
- 진행 중인 주문은 완료 후 정지 적용 (구매자 보호)
- 정지 사유 및 기간을 이메일로 통보

### 4.3 정지 중 처리

- 계정 정지 기간 중 기 구매 상품 반품/교환은 CS 전화 통해 처리 가능
- 적립 포인트는 정지 기간 동안 동결 (소멸하지 않음)
- 구독 서비스는 정지 기간 중 자동 일시정지 처리

## 5. 이의신청 방법

### 5.1 이의신청 자격
- 모든 계정 정지 처분에 대해 이의신청 가능
- 정지 통보일로부터 **30일 이내** 신청

### 5.2 이의신청 방법

**이메일 신청** (권장):
- 이메일: appeal@stylecommerce.co.kr
- 제목: "[계정 이의신청] 계정 이메일 주소"
- 내용: 이의신청 사유, 위반이 아님을 입증하는 자료

**전화 신청**:
- 1588-0000 → ARS 4번 (계정 관련 문의)
- 평일 09:00~18:00

### 5.3 이의신청 처리 절차

1. 신청 접수 확인 이메일 발송 (1 영업일 이내)
2. 담당 팀 검토 (5~10 영업일)
3. 결정 통보 이메일 발송
4. 이의신청 인정 시: 즉시 계정 복구 + 사과 포인트 지급

### 5.4 이의신청 결과

| 결과 | 처리 |
|------|------|
| 이의신청 인정 | 계정 즉시 복구 + 2,000 포인트 보상 |
| 이의신청 부분 인정 | 제재 수위 조정 (예: 영구→30일) |
| 이의신청 기각 | 원 처분 유지, 사유 상세 안내 |

## 6. 계정 복구

### 정지 기간 만료 후 자동 복구
- 7일/30일 정지: 기간 만료 다음 날 자동 복구
- 단, 동일 위반 재발 시 다음 단계 제재 적용

### 영구 정지 계정
- 영구 정지 계정은 복구 불가 원칙
- 단, 법적 판결 또는 이의신청 인정 시 예외적 복구 가능
