# 반품 거절 가능 사유

## 개요

전자상거래법 제17조 제2항은 소비자의 청약철회권이 제한되는 경우를 명시하고 있습니다. 스타일커머스는 이 규정에 따라 아래 사유에 해당하는 경우 반품을 거절할 수 있습니다. 단, 거절 사유는 명확히 입증되어야 하며, 의심스러운 경우에는 소비자에게 유리하게 해석합니다.

---

## 반품 거절 가능 사유 (전자상거래법 제17조 제2항)

### 1. 소비자 귀책 사유로 인한 상품 훼손

**법적 근거**: 전자상거래법 제17조 제2항 제1호

**해당 사례**:
- 착용/사용으로 인한 세탁 흔적, 냄새, 오염
- 소비자 과실로 발생한 스크래치, 파손, 변형
- 원래 포장 상태를 복원 불가하게 훼손한 경우
- 고의적 손상이 의심되는 경우

**판단 기준**:
- 단순 개봉은 훼손으로 보지 않음 (내용 확인 목적)
- 시착/작동 확인 수준의 사용은 허용 (과도한 사용 제외)
- 분쟁 시 검수팀의 사진 증거를 기준으로 판단

**CS 처리 방법**: 훼손 사진을 첨부하여 반품 거절 사유를 소비자에게 서면으로 통보. 소비자가 이의 제기 시 재검수 요청 가능.

---

### 2. 포장 개봉 디지털 콘텐츠

**법적 근거**: 전자상거래법 제17조 제2항 제5호

**해당 상품 유형**:
- CD, DVD, 소프트웨어 패키지 (봉인 해제 후)
- 시리얼 키가 포함된 게임/소프트웨어
- 스크래치 복권형 번호 확인이 필요한 쿠폰

**주의사항**:
- 포장만 개봉했더라도 복제 가능성이 있는 디지털 콘텐츠는 반품 불가
- 단, 상품에 결함이 있는 경우에는 반품/교환 가능
- "내용물 확인 불가 포장"(밀봉된 도서 제외)에는 적용 불가

---

### 3. 맞춤 제작 상품

**법적 근거**: 전자상거래법 제17조 제2항 제2호

**해당 사례**:
- 소비자 요청으로 이름, 사진, 문구 등을 각인/인쇄한 상품
- 치수를 측정하여 개별 제작한 맞춤 의류
- 특정 색상/사이즈 조합으로 주문 제작된 경우
- 단, 표준 옵션(색상/사이즈 선택)은 맞춤 제작으로 보지 않음

**판단 기준**:
- 주문 시 "맞춤 제작" 동의를 받은 경우에만 적용
- 동의 없이 제작한 경우 사업자 귀책으로 봄

---

### 4. 시간이 지난 생물/유통기한 상품

**법적 근거**: 전자상거래법 제17조 제2항 제3호, 제4호

**해당 상품 유형**:
- 신선식품 (채소, 과일, 육류, 수산물)
- 유통기한이 짧은 가공식품
- 생화, 화분

**예외**:
- 배송 중 파손/변질이 발생한 경우 → 사업자 귀책으로 반품/교환 가능
- 수령 시 이미 유통기한이 지난 경우 → 즉시 신고 (수령 후 24시간 이내)

---

## 반품 거절 불가 사유 (주의)

다음의 경우는 반품을 거절할 수 없습니다:

| 상황 | 설명 |
|------|------|
| 상품 결함/하자 | 제조상 결함은 소비자 귀책이 아님 |
| 광고와 다른 상품 | 표시·광고법 위반으로 전면 반품 허용 |
| 단순 개봉 | 내용 확인 목적의 포장 개봉 |
| 착용 없는 의류 시착 | 제한적 확인 행위 허용 |

---

## CS 에이전트 처리 지침

1. **반품 거절 전 반드시 상품 수령 사진 확인** — 시각적 증거 없는 거절은 금지
2. **거절 사유는 법적 조항 명시** — "정책상 불가"가 아닌 전자상거래법 제17조 제2항 X호를 언급
3. **에스컬레이션 기준**: 소비자가 강하게 이의 제기 시 즉시 팀장급으로 에스컬레이션
4. **분쟁 조정 안내**: 한국소비자원 분쟁조정 신청 가능함을 반드시 안내

---

## 관련 법령

- 전자상거래 등에서의 소비자보호에 관한 법률 제17조 제2항
- 공정거래위원회 소비자분쟁해결기준 (별표)
- 표시·광고의 공정화에 관한 법률
