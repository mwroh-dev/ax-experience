# 스타일커머스 반품 절차 안내

**버전**: v3.1 | **시행일**: 2024년 1월 1일

---

## 반품 처리 전체 흐름

```
[1단계] 반품 신청
    → 온라인/전화/채팅으로 접수
    → 신청 사유 선택 및 접수 번호 발급

[2단계] 수거 예약
    → 신청 후 1~2 영업일 내 수거기사 배정
    → SMS로 수거 일정 안내
    → 소비자 부재 시 재예약 가능 (1회)

[3단계] 상품 검수
    → 수거 완료 후 1~2 영업일 내 검수
    → 검수 결과 SMS/앱 알림

[4단계] 환불 처리
    → 검수 통과 시 즉시 환불 승인
    → 결제수단별 1~7 영업일 내 환불 완료
```

---

## 1단계: 반품 신청

### 신청 가능 시점
- 상품 수령 후 14일 이내 (단순 변심)
- 하자 상품은 품질보증 기간 내

### 신청 방법별 안내

#### 앱/웹 신청 (권장)
1. 스타일커머스 앱 또는 웹사이트 로그인
2. 마이페이지 → 주문내역
3. 반품할 주문 선택 → '반품 신청' 버튼
4. 반품 사유 선택:
   - 단순 변심
   - 상품 불량/하자
   - 오배송
   - 배송 중 파손
   - 광고와 다른 상품
5. 상세 설명 입력 (하자/불량 시 사진 첨부 필수)
6. 환불 방법 선택
7. 신청 완료 → 접수 번호 발급 및 안내 SMS 발송

#### 전화 신청
- 번호: 1588-0000 (평일 09:00~18:00, 토 09:00~13:00)
- 준비물: 주문번호, 반품 사유
- ARS에서 '1번' (반품/교환/환불) 선택 후 상담원 연결

#### 채팅 신청
- 앱 내 우측 하단 채팅 아이콘
- 24시간 운영 (야간/주말 AI 자동 응대, 복잡한 사안은 익일 연결)

---

## 2단계: 수거 예약

### 수거 방식

#### 스타일커머스 무료 수거 (권장)
- 신청 완료 후 수거기사 자동 배정
- 수거 가능 시간: 평일 09:00~18:00
- 수거 전날 SMS 안내 및 당일 아침 수거 시간 재안내
- 수거기사 도착 시 반송장 부착 후 전달 (반송장은 수거기사가 지참)

#### 직접 반송 (소비자 선택)
- 스타일커머스 지정 택배사: CJ대한통운, 한진택배, 로젠택배
- 반송 주소: 경기도 이천시 마장면 이치로 123 스타일커머스 물류센터
- 운송장에 주문번호 반드시 기재
- 반송 택배비 선불 발송 (단순 변심의 경우)

### 수거 불가 상황 처리
- 부재 시: 수거기사 연락 후 1회 재방문 가능 (최대 3일 내)
- 3일 내 수거 불가 시 자동 반품 신청 취소 (재신청 필요)
- 공동주택 경비실 위탁 수거 가능 (사전 안내 후 가능)

---

## 3단계: 상품 검수

### 검수 항목
- 상품 상태: 미사용 여부, 훼손 여부
- 수량/구성: 반품 상품과 신청 내역 일치 여부
- 포장 상태: 원래 포장 복원 가능 여부
- 부속품: 태그, 설명서, 구성품 포함 여부

### 검수 결과별 처리

| 결과 | 처리 |
|------|------|
| 검수 통과 | 즉시 환불 승인 |
| 부분 통과 (일부 훼손) | 차감 후 부분 환불 안내 → 소비자 동의 후 처리 |
| 검수 거절 (전량 훼손) | 거절 사유 및 사진 포함 통보 |

### 검수 거절 후 처리
- 거절 사유와 상품 상태 사진을 소비자에게 발송
- 소비자 이의 제기 가능 (3영업일 이내)
- 이의 제기 시 재검수 진행
- 재검수 결과 이견 있을 시 외부 기관 조정 안내

---

## 4단계: 환불 처리

검수 통과 후 환불 처리 (결제수단별 기한):
- 카드: 3~7 영업일
- 계좌이체: 1~3 영업일 (환불 계좌 사전 등록 필요)
- 포인트: 1 영업일

환불 완료 시 앱 푸시 및 SMS 안내.

---

## 반품 관련 자주 발생하는 문제

### 반송장 없이 수거기사가 온 경우
- 수거기사에게 주문번호 안내 시 현장 반송장 출력 가능

### 상품 일부만 반품하고 싶은 경우
- 신청 단계에서 반품 수량/상품 선택 가능
- 세트 상품은 전량 반품 원칙 (부분 반품 시 팀장 승인 필요)

### 반품 신청 취소하고 싶은 경우
- 수거 전: 앱/웹에서 즉시 취소 가능
- 수거 후: 물류센터 도착 전까지 전화로 요청 가능 (이후 불가)
