# 배송 추적 자주 묻는 질문 (FAQ)

---

Q: 주문한 상품의 배송 현황은 어떻게 확인하나요?

A: 두 가지 방법으로 배송 현황을 확인할 수 있습니다.

**방법 1: 스타일커머스 앱/웹**
1. 마이페이지 → 주문내역
2. 배송 중인 주문 선택
3. '배송 추적' 버튼 클릭
4. 실시간 배송 위치 및 예상 도착일 확인

**방법 2: 택배사 직접 조회**
- 출고 완료 시 발송된 SMS의 운송장 번호 확인
- 담당 택배사 앱 또는 홈페이지에서 직접 조회
  - CJ대한통운: www.doortodoor.co.kr
  - 한진택배: www.hanjin.co.kr
  - 로젠택배: www.ilogen.com

---

Q: 상품이 출고됐다고 하는데 운송장 번호를 못 받았습니다.

A: 출고 시 SMS와 앱 푸시 알림으로 운송장 번호를 발송합니다. 다음을 확인해 보세요:

1. SMS 수신 차단 여부 확인 (스팸 처리됐을 수 있음)
2. 앱 알림 설정 확인 (앱 → 설정 → 알림)
3. 앱/웹에서 직접 확인: 마이페이지 → 주문내역 → '배송 조회'

위 방법으로 확인이 안 되는 경우 고객센터(1588-0000)로 주문번호를 알려주시면 운송장 번호를 바로 안내해 드립니다.

---

Q: 배송 추적 상태가 오랫동안 변경되지 않습니다.

A: 배송 추적 정보는 물류 거점에서 스캔될 때만 업데이트됩니다. 일부 구간에서는 12~24시간 동안 업데이트가 없을 수 있습니다.

**정상 상황**:
- 지역 허브 이동 중 (도로 운송 구간)
- 야간/새벽 배송 전 대기 중

**비정상 상황 (문의 필요)**:
- 48시간 이상 동일 상태 유지
- '오류' 또는 '반송' 표시

48시간 이상 업데이트가 없는 경우 고객센터에 문의해 주세요. 택배사에 직접 확인하여 현황을 안내해 드립니다.

---

Q: 앱에서 '배달 완료'로 표시되는데 상품을 못 받았습니다.

A: 배달 완료로 표시되어도 실제 수령이 안 된 경우가 있습니다. 다음을 먼저 확인해 주세요:

**1. 경비실/무인 택배함 확인**
- 공동주택의 경우 경비실이나 무인 택배함에 보관되어 있을 수 있습니다

**2. 가족/동거인 수령 여부 확인**
- 다른 가구원이 대신 수령했을 수 있습니다

**3. 현관 앞 확인**
- 문 앞에 두고 간 경우 사진을 찍은 후 가는 경우가 있습니다 (배달 완료 사진 확인 요청 가능)

위 확인 후에도 상품을 받지 못한 경우, 즉시 고객센터에 신고해 주세요.

---

Q: 상품을 못 받았을 때 미배달 신고는 어떻게 하나요?

A: 미배달 신고 절차는 다음과 같습니다.

**신고 방법**:
- 앱/웹: 주문내역 → '배달 완료' 상태 주문 → '미수령 신고'
- 전화: 1588-0000

**신고 시 필요 정보**:
- 주문번호
- 배달 완료로 표시된 날짜 및 시간
- 경비실/무인 택배함 확인 여부

**처리 절차**:
1. 신고 접수
2. 택배사에 배달 경위 조사 요청 (1~3 영업일)
3. 조사 결과 공유
4. 미수령 확인 시: 재발송 또는 환불 처리 (소비자 선택)

**주의**: 배달 완료 후 7일이 경과하면 신고가 어려울 수 있으니 즉시 신고해 주세요.

---

Q: 주소를 잘못 입력해서 배송이 잘못 간 것 같습니다.

A: 주소 오류로 인한 배송 오류는 소비자 귀책입니다. 그러나 최대한 도와드리겠습니다.

**출고 전 주소 변경**:
- 앱에서 직접 변경 가능 (주문 상태 '결제 완료' 상태에서만)
- 이미 출고된 경우 변경 불가

**출고 후 잘못된 주소로 발송된 경우**:
1. 즉시 고객센터 신고
2. 택배사에 배송지 변경 요청 (배송 중인 경우 가능할 수 있음)
3. 이미 해당 주소에 배달된 경우 수취인과 직접 소통 필요
4. 회수 불가 시 재구매 안내 (원래 주문 환불 불가)

---

Q: 해외 직구 상품인데 통관이 오래 걸립니다.

A: 해외 직구 통관은 세관의 검사 기간에 따라 달라집니다.

- **정상 통관**: 3~5 영업일
- **검사 대상 선정**: 5~10일 추가 소요
- **서류 보완 요청**: 서류 제출 후 추가 3~5일

통관 현황은 관세청 '유니패스' (unipass.customs.go.kr)에서 확인 가능합니다.
20일 이상 통관이 지연되는 경우 고객센터로 문의해 주세요.
