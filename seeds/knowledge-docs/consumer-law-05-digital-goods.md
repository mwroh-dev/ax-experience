# 디지털 재화 청약철회 예외 규정

## 개요

디지털 상품은 물리적 상품과 다르게 복제·전달이 용이하여, 전자상거래법 제17조 제2항 제5호는 특정 조건하에 청약철회를 제한하고 있습니다. 스타일커머스는 이 규정을 엄격히 적용하되, 소비자에게 불이익이 없도록 명확한 기준을 운영합니다.

---

## 디지털 재화의 정의

스타일커머스에서 판매되는 디지털 재화의 유형:

| 유형 | 예시 |
|------|------|
| 다운로드 콘텐츠 | 전자책(e-book), 디지털 앨범, PDF 자료, 폰트 파일 |
| 스트리밍 서비스 | 동영상 강의, 오디오 콘텐츠 |
| 소프트웨어 라이선스 | 앱 구독권, 소프트웨어 시리얼 키 |
| 이용권 | 게임 아이템, 가상화폐, 쿠폰 코드 |
| 디지털 서비스 | 클라우드 스토리지, 디자인 템플릿 |

---

## 청약철회 제한 조건

전자상거래법 제17조 제2항 제5호에 따라, 다음 **두 가지 조건을 모두 충족**한 경우에만 청약철회를 제한할 수 있습니다:

### 조건 1: 소비자 동의 취득
- 구매 전 청약철회 제한 사실을 소비자에게 고지
- 소비자가 명시적으로 동의 (체크박스 등)
- 동의 기록이 시스템에 저장되어 있어야 함

### 조건 2: 복제 가능성 충족
- 다운로드 또는 사용으로 인해 복제본이 소비자에게 남아있는 상태
- 단순 구매만으로는 제한 불가

**중요**: 소비자 동의 없이는 디지털 콘텐츠라도 청약철회를 제한할 수 없습니다.

---

## 다운로드 콘텐츠 청약철회 제한 기준

### 제한 가능한 경우
- 다운로드 완료 후 (파일이 소비자 기기에 저장된 상태)
- 스트리밍 콘텐츠를 일부라도 시청/청취한 후
- 시리얼 키를 확인하거나 입력한 후

### 제한 불가한 경우 (반드시 환불 처리)
- 구매 후 다운로드/사용 전 (콘텐츠 미전송 상태)
- 다운로드 오류로 인해 콘텐츠를 수신하지 못한 경우
- 콘텐츠 내용이 표시 정보와 현저히 다른 경우
- 구매 전 동의를 받지 않은 경우

---

## 부분 이용 시 환불 처리

### 스트리밍/강의 콘텐츠

소비자가 일부만 시청한 경우 잔여분에 대한 환불 가능 여부:

**원칙**: 전자상거래법상 명시적 규정 없으나, 스타일커머스 자체 정책으로 다음 기준 적용:

| 이용 비율 | 환불 가능 여부 | 비고 |
|-----------|---------------|------|
| 0% (미이용) | 전액 환불 | 구매 후 7일 이내 |
| 1~10% 이하 | 환불 가능 (검토 후) | 콘텐츠 결함 여부 확인 |
| 11~50% | 부분 환불 (사안별 판단) | 팀장급 에스컬레이션 |
| 51% 이상 | 원칙적 환불 불가 | 결함 있을 경우 예외 |

### 구독 서비스 중도 해지
구독 서비스의 해지는 `consumer-law-06-subscription-cancel.md` 참조.

## 콘텐츠 결함 시 처리 (중요)

디지털 콘텐츠에 결함이 있는 경우에는 청약철회 제한 규정이 적용되지 않습니다:

### 결함으로 인정되는 경우
- 다운로드한 파일이 실행/재생되지 않는 경우
- 일부 콘텐츠 누락 (예: 강의 목록 중 일부 영상 없음)
- 실제 내용이 설명과 현저히 다른 경우
- 불법 복제 또는 저작권 문제로 서비스 중단된 경우

### 처리 방법
1. 콘텐츠 결함 사진/스크린샷 첨부하여 CS 접수
2. 담당자 확인 후 1영업일 이내 처리 방향 안내
3. 결함 확인 시 전액 환불 (이용 여부와 무관)

---

## CS 에이전트 체크리스트

디지털 상품 환불 요청 접수 시:
- [ ] 구매 시 청약철회 제한 동의를 받았는지 확인
- [ ] 다운로드/이용 여부 확인
- [ ] 콘텐츠 결함 여부 확인
- [ ] 이용 비율 확인 (로그 데이터 참조)
- [ ] 구매 후 7일 이내 여부 확인

---

## 관련 법령

- 전자상거래 등에서의 소비자보호에 관한 법률 제17조 제2항 제5호
- 콘텐츠산업 진흥법 제27조 (콘텐츠 이용자 보호)
- 공정거래위원회 디지털콘텐츠 관련 소비자분쟁해결기준
