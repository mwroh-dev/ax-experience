# 환불 상태 확인 자주 묻는 질문 (FAQ)

---

Q: 반품 신청 후 환불이 어떤 상태인지 어떻게 확인하나요?

A: 환불 처리 현황은 스타일커머스 앱 또는 웹에서 실시간 확인할 수 있습니다.

**확인 방법**:
1. 앱 또는 웹 로그인
2. 마이페이지 → '반품/취소 내역'
3. 해당 주문 선택 → 처리 단계 확인

**처리 단계 안내**:
- **반품 접수**: 신청이 완료된 상태
- **수거 예약**: 택배 수거 일정이 잡힌 상태
- **수거 완료**: 상품이 물류센터에 도착한 상태
- **검수 중**: 상품 상태를 확인하는 단계
- **검수 완료**: 검수가 끝나고 환불 승인된 상태
- **환불 처리 완료**: 결제사에 환불 요청이 완료된 상태

'환불 처리 완료' 단계 이후에는 결제수단별로 추가 시간이 소요됩니다.

---

Q: '환불 처리 완료' 상태인데 카드에 돈이 들어오지 않았습니다. 언제 들어오나요?

A: 결제수단별로 실제 환불 반영까지의 기간이 다릅니다.

| 결제수단 | 처리 완료 후 소요 시간 |
|---------|---------------------|
| 신용카드 | 3~7 영업일 |
| 체크카드 | 3~5 영업일 |
| 계좌이체 | 1~3 영업일 |
| 카카오페이 | 1~5 영업일 |
| 네이버페이 | 1~5 영업일 |
| 포인트 | 1 영업일 이내 |

카드사에 따라 처리 속도가 다르며, 이미 청구된 경우 다음 달 청구서에서 차감될 수 있습니다. 카드사 고객센터에 직접 확인하시면 더 정확한 시점을 안내받을 수 있습니다.

---

Q: 환불 신청한 지 2주가 지났는데 아직 환불이 안 됐습니다.

A: 법정 처리 기한(환불 승인 후 3영업일)을 초과한 경우 지연이자 청구 권리가 발생합니다. 즉시 고객센터로 문의해 주세요.

**문의 방법**:
- 전화: 1588-0000 (평일 09:00~18:00)
- 채팅: 앱 내 24시간 채팅
- 이메일: cs@stylecommerce.co.kr

**문의 시 필요 정보**:
- 주문번호
- 반품 신청일
- 결제수단

스타일커머스 귀책 지연의 경우 지연 기간에 대한 이자(연 15%)를 추가로 지급합니다.

---

Q: 취소는 했는데 앱에서 '환불 완료'가 뜨지 않습니다.

A: 앱의 상태 표시는 실시간이 아닐 수 있습니다. 다음을 확인해 주세요:

1. 앱을 닫고 다시 실행 (캐시 갱신)
2. 취소 완료 이메일 또는 SMS 확인
3. 앱 상태와 실제 카드 내역 비교

앱에는 '처리 중'으로 표시되어 있더라도 실제 카드 취소가 이루어졌을 수 있습니다. 카드사 앱에서 '취소 내역'을 직접 확인해 보세요.

---

Q: 계좌이체로 결제했는데 환불받을 계좌를 어떻게 등록하나요?

A: 계좌이체 결제의 경우 환불 신청 시 환불 계좌를 직접 입력해야 합니다.

**등록 방법**:
1. 반품/취소 신청 화면에서 '환불 방법 선택'
2. '계좌이체' 선택
3. 은행명, 계좌번호, 예금주명 입력
4. 저장 후 신청 완료

**주의사항**:
- 예금주명은 주문자 이름과 동일해야 함 (다른 경우 신분증 사본 필요)
- 잘못된 계좌 입력 시 환불 실패 → CS 재접수 필요
- 이미 폐쇄된 계좌 입력 시 반송 처리 → 재등록 필요

---

Q: 분할납부(할부)로 결제한 경우 환불은 어떻게 되나요?

A: 할부 결제의 경우 일시불로 취소 처리됩니다.

- 아직 청구되지 않은 할부금: 취소 처리 (청구 없음)
- 이미 청구된 할부금: 카드사에서 환불 처리 (보통 다음 달 청구서에서 차감)
- 이자 발생 할부(3개월 이상 유이자 할부): 이자는 카드사에 별도 확인 필요

할부 환불 관련 이자 처리는 카드사 정책에 따라 다르므로 카드사 고객센터에 직접 확인하시기 바랍니다.

---

Q: 포인트로 결제한 부분은 어떻게 환불되나요?

A: 포인트 사용분은 포인트로 복구됩니다.

- 복구 시기: 환불 처리 완료 후 1 영업일 이내
- 복구 포인트의 유효기간: 원래 유효기간 그대로 복구
- 확인 방법: 마이페이지 → '포인트 내역'

이미 소멸된 포인트는 복구되지 않습니다 (소멸 후 환불 시 해당 금액은 계좌 입금 처리).
