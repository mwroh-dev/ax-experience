# 스타일커머스 교환 정책

**버전**: v2.2 | **시행일**: 2024년 1월 1일

---

## 교환 원칙

교환은 동일 상품 내에서 옵션(사이즈, 색상 등)을 변경하거나, 하자 상품을 정상 상품으로 교체하는 서비스입니다. 다른 상품으로의 교환은 지원하지 않으며, 이 경우 반품 후 재구매를 이용하셔야 합니다.

---

## 교환 가능 사유

### 사업자 귀책 교환 (무조건 교환)

| 사유 | 내용 |
|------|------|
| 상품 불량/하자 | 제조상 결함, 기능 이상, 소재 불량 |
| 오배송 | 주문한 것과 다른 상품/옵션 배송 |
| 배송 중 파손 | 포장 내 상품 파손 |
| 광고 불일치 | 상세 페이지와 현저히 다른 상품 |

### 소비자 변심 교환 (조건부 교환)

| 사유 | 조건 |
|------|------|
| 사이즈 변경 | 수령 후 7일 이내, 미착용 상태 |
| 색상 변경 | 수령 후 7일 이내, 미사용 상태 |
| 단순 변심 | 수령 후 7일 이내, 교환 재고 있을 때 |

**스타일커머스 자체 확대 정책**: 일부 상품 카테고리는 최초 교환에 한하여 무료 교환을 지원합니다 (아래 참조).

---

## 무료 교환 지원 카테고리 (최초 1회)

다음 카테고리는 구매일로부터 30일 이내 첫 번째 교환을 무료로 지원합니다:

- 의류 (사이즈 교환)
- 신발 (사이즈 교환)
- 속옷/양말 (사이즈 교환, 미착용·위생 포장 유지 시)

**조건**:
- 동일 상품 내 사이즈만 변경 가능
- 교환 재고가 있는 경우에만 가능
- 세일 상품도 동일하게 적용

---

## 교환 불가 사유

- 14일 초과한 단순 변심 (반품으로 처리 후 재구매)
- 소비자 귀책 훼손 (착용, 세탁, 오염)
- 교환 재고 없는 경우 (이 경우 환불 처리)
- 맞춤 제작 상품
- 최종 세일 상품 (별도 표시된 경우)
- 다른 상품으로의 교환

---

## 교환 절차

### Step 1: 교환 신청

**온라인**:
1. 마이페이지 → 주문내역 → 해당 주문 → '교환 신청'
2. 교환 사유 선택
3. 교환 원하는 옵션 선택 (사이즈, 색상)
4. 신청 완료

**전화/채팅**: 주문번호와 교환 옵션 안내 후 접수

### Step 2: 기존 상품 수거

- 수거기사 방문 (신청 후 1~2 영업일)
- 또는 직접 발송 (지정 택배사)

### Step 3: 교환 상품 발송

- 기존 상품 수거 완료 후 교환 상품 발송 (원칙)
- 하자 상품의 경우 수거와 동시에 새 상품 발송 가능 (확인 후 처리)
- 발송 후 운송장 번호 SMS 안내

### Step 4: 교환 완료

- 교환 상품 수령 후 앱 알림

## 배송비 부담 기준

| 교환 사유 | 반송비 | 재배송비 |
|----------|--------|---------|
| 상품 불량/하자 | 스타일커머스 부담 | 스타일커머스 부담 |
| 오배송 | 스타일커머스 부담 | 스타일커머스 부담 |
| 단순 변심 (첫 번째) | 3,000원 | 3,000원 |
| 단순 변심 (두 번째 이상) | 3,000원 | 3,000원 |
| 무료 교환 대상 카테고리 (1회) | 무료 | 무료 |

**도서산간 추가비용**: 제주도 3,000원 추가, 도서 6,000원 추가 (각 편도)

---

## 교환 중 환불 전환

교환 신청 후 다음 상황에서 환불로 전환 가능합니다:

- 교환 재고 품절 (스타일커머스에서 자동 안내)
- 소비자 요청으로 전환 (수거 전까지 가능)
- 교환 상품도 하자가 있는 경우

환불 전환 시 반품 정책 기준 적용.

---

## CS 에이전트 처리 지침

### 교환 신청 검토 시 확인 사항
- [ ] 교환 사유가 사업자 귀책인지 소비자 귀책인지 확인
- [ ] 교환 희망 옵션 재고 확인 (시스템 재고 조회 필수)
- [ ] 소비자 귀책의 경우 배송비 안내
- [ ] 재고 없을 시 환불 전환 여부 확인

### 재고 없을 때 처리
1. 소비자에게 품절 안내
2. 환불 또는 대체 상품 안내 제공
3. 소비자 선택에 따라 처리
