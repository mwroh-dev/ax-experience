# 스타일커머스 CS 답변 템플릿 모음

**버전**: v3.0 | **적용 대상**: 전체 CS 채널 | **시행일**: 2024년 1월 1일

> **사용 지침**: 아래 템플릿은 가이드라인이며, 상황에 맞게 자연스럽게 변형하여 사용하세요.
> 대괄호 `[ ]` 안의 내용은 실제 정보로 교체해야 합니다.

## 1. 환불 관련 템플릿

### 1-A. 환불 접수 완료 안내

```
안녕하세요, [고객명]님. 스타일커머스 CS팀입니다.

[주문번호]에 대한 환불 신청이 접수되었습니다.

처리 일정은 다음과 같습니다:
- 반품 수거: [수거 예정일]
- 검수 완료: 수거 후 1~2 영업일
- 환불 처리: 검수 완료 후 [결제수단]으로 [X]영업일 이내

처리 단계별로 앱 알림과 SMS를 보내드립니다.
추가 문의 사항은 언제든지 연락해 주세요.

감사합니다.
스타일커머스 CS팀
```

---

### 1-B. 환불 완료 안내

```
안녕하세요, [고객명]님. 스타일커머스입니다.

[주문번호]의 환불 처리가 완료되었습니다.

- 환불 금액: [환불금액]원
- 환불 방법: [카드 취소/계좌 입금/포인트 복구]
- 반영 예상 시간: [X~X 영업일]

카드사 처리 기간에 따라 실제 반영까지 시간이 소요될 수 있습니다.
[X 영업일] 이후에도 확인되지 않으시면 카드사 고객센터에 문의하시거나,
저희에게 다시 연락해 주세요.

불편을 드려서 죄송하며, 다음에는 더 나은 쇼핑 경험을 제공해 드리겠습니다.
감사합니다.
```

---

### 1-C. 환불 불가 안내 (소비자 귀책)

```
안녕하세요, [고객명]님. 스타일커머스 CS팀입니다.

[주문번호]의 반품 건을 검토한 결과, 아래 사유로 환불 처리가 어렵게 되었습니다.

사유: [착용 흔적 발견 / 포장 훼손 / 유효기간 초과 등 구체적 사유]

저희 환불 정책(전자상거래법 제17조 제2항 기준)에 따라 소비자 귀책으로 인한 상품 훼손의 경우 환불이 제한됩니다.

이 결정에 동의하지 않으시는 경우:
1. 재검수 요청: [X]일 이내 저희에게 이의를 제기해 주시면 재검토해 드립니다
2. 외부 조정 신청: 한국소비자원(1372)에 피해구제를 신청하실 수 있습니다

상품 반환을 원하시는 경우 착불로 반송해 드립니다.

불편을 드려서 죄송합니다.
스타일커머스 CS팀
```

---

### 1-D. 환불 지연 사과 및 처리 안내

```
안녕하세요, [고객명]님. 스타일커머스 CS팀입니다.

환불 처리가 지연되어 정말 죄송합니다. 많이 기다리셨을 것 같아 다시 한번 사과드립니다.

현재 상황 확인 결과: [지연 사유 설명]

처리 완료 예정일: [날짜]
추가 보상: 불편을 드린 점에 대해 [포인트]P를 드리겠습니다 (마이페이지 확인).

법정 처리 기한(3영업일) 초과 시 지연이자(연 15%)도 함께 지급해 드립니다.

[처리 완료 예정일] 이후에도 환불이 되지 않으시면 즉시 연락해 주세요.

다시 한번 사과드립니다.
스타일커머스 CS팀
```

### 1-E. 부분 환불 안내

```
안녕하세요, [고객명]님. 스타일커머스 CS팀입니다.

[주문번호]에 대한 부분 환불 처리 내역을 안내해 드립니다.

반품 상품: [상품명]
원 결제 금액: [금액]원
부분 환불 금액: [금액]원

[환불 금액이 원 결제 금액과 다른 경우 사유 설명:
예) 쿠폰 안분 적용으로 할인 비율에 따라 계산되었습니다 /
나머지 주문이 무료배송 기준(50,000원) 이하로 낮아져 배송비 3,000원이 차감되었습니다]

환불 방법: [결제수단]으로 [X]영업일 이내 처리됩니다.

궁금한 점이 있으시면 언제든지 연락 주세요.
```

## 2. 반품 관련 템플릿

### 2-A. 반품 신청 접수 완료

```
안녕하세요, [고객명]님.

[주문번호]의 반품 신청이 완료되었습니다.

■ 수거 일정: [수거 예정일] (평일 09:00~18:00)
■ 수거 방법: 택배 수거기사가 방문합니다 (반송장 지참)
■ 부재 시: [연락처]로 연락 주시면 일정을 재조율해 드립니다

■ 반드시 준비해 주세요:
- 상품 원래 포장재 (없는 경우 새 박스로 포장)
- 부속품, 태그, 구성품 전체 포함

수거 완료 후 검수를 진행하며, 결과는 앱 알림으로 안내해 드립니다.
```

---

### 2-B. 반품 거절 안내

```
안녕하세요, [고객명]님.

[주문번호] 반품 건에 대해 아래와 같이 안내해 드립니다.

검수 결과 [구체적 사유: 착용 흔적 / 원포장 훼손 / 유통기한 경과 등]으로 인해 반품 처리가 어렵게 되었습니다.

이에 해당하는 법적 근거는 전자상거래법 제17조 제2항 [X]호입니다.

확인을 원하시면 상품 상태 사진을 이메일로 보내드릴 수 있습니다.
이의 제기는 본 통보로부터 [7]일 이내에 해주세요.

상품 반환을 원하시는 경우 착불로 반송해 드리겠습니다.
```

## 3. 교환 관련 템플릿

### 3-A. 교환 접수 완료

```
안녕하세요, [고객명]님.

[주문번호]의 교환 신청이 완료되었습니다.

■ 교환 사유: [고객 기재 사유]
■ 교환 상품: [상품명] [기존 옵션] → [교환 옵션]
■ 수거 일정: [날짜] (수거기사 방문)
■ 재발송 예정: 수거 완료 후 1~3 영업일

[사업자 귀책인 경우] 교환에 관한 배송비는 저희가 전액 부담합니다.
[소비자 귀책인 경우] 교환 배송비 [3,000원]은 환불 금액에서 차감됩니다.
```

---

### 3-B. 교환 재고 없음 안내

```
안녕하세요, [고객명]님.

교환 신청하신 [상품명] [옵션]이 현재 품절 상태로 교환이 어렵습니다.

다음 중 원하시는 처리 방법을 알려주세요:

1. 전액 환불: 원래 결제 금액으로 환불해 드립니다
2. 재입고 알림 신청: 입고 시 알림을 받으시고 교환 또는 재구매 가능
3. 대체 상품 안내: 유사 상품을 찾아드릴 수 있습니다

희망하시는 방법을 알려주시면 바로 처리해 드리겠습니다.
```

## 4. 배송 관련 템플릿

### 4-A. 배송 지연 안내

```
안녕하세요, [고객명]님.

주문하신 [상품명]의 배송이 예상보다 지연되고 있어 죄송합니다.

현재 상황: [배송사 허브 적체 / 날씨 영향 / 지역 배송 지연 등 구체 사유]
배송 예상일: [예상 날짜]

배송이 완료되지 않는 경우 [연락처]로 연락 주시면 재발송 또는 환불 처리를 도와드립니다.

불편을 드려서 진심으로 사과드리며, 기다려 주셔서 감사합니다.
```

---

### 4-B. 미배달 신고 접수 완료

```
안녕하세요, [고객명]님.

미수령 신고가 접수되었습니다. 빠른 확인 후 조치해 드리겠습니다.

■ 처리 절차:
1. 택배사 배달 경위 조사 (1~3 영업일)
2. 조사 결과 안내
3. 미수령 확인 시: 재발송 또는 환불 (선택 가능)

경비실, 무인 택배함, 가족 수령 여부도 한 번 더 확인해 주시면 감사하겠습니다.
조사 결과가 나오는 대로 바로 연락드리겠습니다.
```

---

### 4-C. 오배송 접수 완료

```
안녕하세요, [고객명]님.

오배송 신고가 접수되었습니다. 불편을 드려서 진심으로 사과드립니다.

■ 처리 내용:
- 잘못 배송된 상품 무료 수거 ([예정일])
- 올바른 상품 재발송 (재고 확인 후 [예정일])

잘못 배송된 상품은 사용하지 마시고 보관해 주시기 바랍니다.
재고 부족 시 환불로 처리해 드리며, 이 경우 사전에 안내드리겠습니다.
```
