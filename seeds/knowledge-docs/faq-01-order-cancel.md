# 주문 취소 자주 묻는 질문 (FAQ)

---

Q: 주문 후 바로 취소하고 싶습니다. 어떻게 하나요?

A: 주문 완료 후 아직 출고 전이라면 앱/웹에서 즉시 취소 가능합니다.

**취소 방법**:
1. 스타일커머스 앱 또는 웹 로그인
2. 마이페이지 → 주문내역
3. 취소할 주문 선택
4. '주문 취소' 버튼 클릭
5. 취소 사유 선택 후 최종 확인

취소 완료 즉시 결제 취소가 진행되며, 카드의 경우 3~7 영업일 내 승인 취소됩니다.

---

Q: 주문한 지 시간이 지났는데 아직 취소 가능한가요?

A: 주문 상태에 따라 달라집니다.

| 주문 상태 | 취소 가능 여부 |
|----------|-------------|
| 결제 완료 (출고 전) | 가능 (앱/웹 직접 취소) |
| 상품 준비 중 | 가능하나 처리 지연될 수 있음 (CS 문의 필요) |
| 배송 중 (운송장 발행 후) | 불가 → 수령 후 반품으로 처리 |
| 배달 완료 | 불가 → 반품 신청 |

배송 중인 경우 배송지에서 수령을 거부하거나, 수령 후 반품 신청해 주세요.

---

Q: 배송 중 상태인데 주문을 취소할 수 있나요?

A: 배송 중 상태에서는 직접 취소가 불가합니다. 다음 방법을 이용하세요:

**방법 1: 배달 거부**
- 배달원 도착 시 수령 거부
- 거부 시 반품으로 처리되어 물류센터로 반송됨
- 단, 이 경우 반송비 3,000원이 발생할 수 있습니다

**방법 2: 수령 후 반품 신청**
- 수령 후 14일 이내 반품 신청
- 마이페이지 → 주문내역 → '반품 신청'

단순 변심의 경우 반품비(3,000원)가 소비자 부담이 됩니다.

---

Q: 취소 버튼이 비활성화되어 있어서 클릭이 안 됩니다.

A: 이미 출고 처리가 시작되어 앱에서 직접 취소가 어려운 상태입니다. 고객센터로 연락해 주세요.

- **전화**: 1588-0000 (평일 09:00~18:00)
- **채팅**: 앱 내 채팅 상담 (24시간)

주문번호를 알려주시면 가능 여부를 확인하여 빠르게 처리해 드리겠습니다.

---

Q: 여러 개의 상품을 주문했는데 일부만 취소하고 싶습니다.

A: 묶음 주문에서 일부 상품만 취소할 수 있습니다.

**취소 방법**:
1. 마이페이지 → 주문내역 → 해당 주문 선택
2. '일부 취소' 또는 개별 상품 옆 '취소' 버튼 선택
3. 취소할 상품/수량 선택 후 확인

**주의사항**:
- 일부 취소 후 주문금액이 무료배송 기준(50,000원) 이하로 낮아지면 배송비 3,000원이 차감됩니다
- 단, 모든 상품이 같은 배송지/배송건이어야 일부 취소 가능

---

Q: 취소 완료 후 환불이 안 됩니다. 어디서 확인하나요?

A: 취소 완료 후 환불 처리 상태는 다음에서 확인할 수 있습니다:

1. 앱/웹: 마이페이지 → '취소/환불 내역'
2. 결제수단별 처리 기간:
   - 신용카드: 3~7 영업일
   - 계좌이체: 1~3 영업일
   - 포인트: 1 영업일 이내

환불 기한 내 미처리 시 고객센터(1588-0000)로 주문번호와 함께 문의해 주세요.

---

Q: 명절/공휴일에 주문했는데 취소가 안 됩니다.

A: 공휴일에도 앱/웹에서 출고 전 주문 취소는 24시간 가능합니다. 단, CS 상담원 연결은 영업일(평일 09:00~18:00)에만 가능합니다. 앱에서 취소가 안 되는 경우 채팅 상담(24시간)을 이용해 주세요.

---

Q: 취소한 주문에서 사용한 쿠폰은 어떻게 되나요?

A: 쿠폰 상태에 따라 다릅니다:
- **유효기간 내 쿠폰**: 자동 재발행 (원래 유효기간 유지)
- **유효기간 만료 쿠폰**: 재발행 불가 (할인 금액 현금으로 환불됨)
- **이벤트 기간 종료 쿠폰**: 이벤트 기간 내 재발행, 이후 불가

쿠폰 재발행 여부는 취소 완료 후 '보유 쿠폰' 목록에서 확인하세요.
