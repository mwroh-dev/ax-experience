# 스타일커머스 쿠폰 및 할인 정책

**버전**: v2.1 | **시행일**: 2024년 1월 1일

---

## 1. 쿠폰 종류

| 쿠폰 유형 | 발행 조건 | 사용 기한 |
|----------|---------|---------|
| 신규 가입 쿠폰 | 첫 가입 시 자동 발행 | 발행 후 30일 |
| 등급 혜택 쿠폰 | 등급 달성/유지 시 | 발행 후 30일 |
| 생일 쿠폰 | 생일 월 1일 자동 발행 | 해당 월 말일 |
| 이벤트 쿠폰 | 이벤트 참여 시 | 이벤트별 상이 |
| 사과 쿠폰 | CS 처리 보상 | 발행 후 90일 |
| 친구 초대 쿠폰 | 친구 초대 완료 시 | 발행 후 60일 |
| 타임 딜 쿠폰 | 특정 시간대 접속 시 | 24시간 |

---

## 2. 쿠폰 적용 기준

### 2.1 기본 적용 조건
- 최소 주문금액 이상 구매 시 적용 가능
- 쿠폰에 명시된 적용 카테고리/브랜드에만 사용 가능
- 쿠폰 유효기간 내에만 사용 가능
- 계정 1개당 동일 쿠폰 1회만 사용 가능

### 2.2 중복 적용 제한

**중복 적용 불가 항목**:
- 쿠폰 + 쿠폰 (2개 이상 쿠폰 동시 사용 불가)
- 쿠폰 + 타임딜 할인 (할인 이미 적용된 상품에 쿠폰 불가)
- 쿠폰 + 묶음 할인 (세트 구성 상품 별도 할인 적용 불가)
- 쿠폰 + 브랜드 이벤트 할인 (별도 표시 상품)

**중복 적용 가능 항목**:
- 쿠폰 + 포인트 (포인트는 쿠폰과 병행 사용 가능)
- 쿠폰 + 멤버십 적립률 (쿠폰 사용해도 포인트 정상 적립)
- 쿠폰 + 카드사 할인 (카드사 자체 할인은 별도 적용)
- 쿠폰 + 생일 혜택 (생일 쿠폰은 별도 혜택으로 인정)

---

## 3. 쿠폰 사용 제한 상품

다음 카테고리/상품은 쿠폰 적용이 불가합니다:
- 이미 30% 이상 할인 적용 중인 상품
- 브랜드관 단독 프로모션 상품 (브랜드 별도 표시)
- 해외 직구 상품 (일부 예외 있음)
- 상품권/기프티콘
- 구독 서비스 신규 가입비

## 4. 환불 시 쿠폰 처리

### 4.1 전체 환불 시

| 쿠폰 상황 | 처리 방법 |
|----------|---------|
| 유효기간 내 쿠폰 사용 | 쿠폰 재발행 (원래 유효기간 유지) |
| 유효기간 만료된 쿠폰 사용 | 재발행 불가 (현금 할인 적용된 것으로 처리) |
| 생일 쿠폰 사용 후 환불 | 해당 월 내 재발행 가능 |
| 이벤트 쿠폰 사용 후 환불 | 이벤트 기간 내 재발행, 이후 불가 |

**환불 금액 계산**: 쿠폰 할인 금액을 포함한 실제 결제 금액 기준으로 환불

예시: 정가 50,000원 상품 → 10,000원 쿠폰 적용 → 40,000원 결제 → 환불 시 40,000원 환불

### 4.2 부분 환불 시 (일부 상품만 반품)

쿠폰이 주문 전체에 적용된 경우, 환불 금액은 다음과 같이 계산합니다:

**안분 계산 방식**:
- 쿠폰 할인액을 각 상품 결제금액 비율로 안분
- 반품 상품의 안분된 쿠폰 할인 적용 후 금액을 환불
- 쿠폰은 재발행 불가 (부분 사용된 것으로 처리)

**예시**:
- 상품 A (30,000원) + 상품 B (20,000원) = 총 50,000원
- 10,000원 쿠폰 적용 → 결제 40,000원
- A: 40,000 × (30/50) = 24,000원, B: 40,000 × (20/50) = 16,000원
- A만 반품 시 → 24,000원 환불

---

## 5. 포인트 환불 처리

### 포인트를 사용하여 결제한 경우
- 전체 환불: 사용한 포인트 전액 복구 (유효기간 원상 복구)
- 부분 환불: 안분 계산 후 해당 포인트 복구

### 포인트 소멸 여부
- 환불로 복구된 포인트의 유효기간: 원래 유효기간 그대로 복구
- 이미 소멸된 포인트는 복구 불가 (소멸 후 환불 시 해당 금액 현금 지급)

---

## 6. 쿠폰 발행 오류 시 처리

스타일커머스 시스템 오류로 잘못 발행된 쿠폰:
- 오류 쿠폰은 사용 전 취소 가능 (소비자 동의 후 취소)
- 이미 사용한 경우 소비자 선의 적용 여부는 사안별 검토
- 명백한 시스템 오류(예: 100% 할인 쿠폰)는 취소 처리 원칙

---

## 7. CS 에이전트 처리 지침

### 쿠폰 관련 문의 처리
- 쿠폰 미적용 문의: 적용 조건 및 유효기간 확인 → 조건 미충족 시 안내
- 쿠폰 분실 문의: 계정 내 쿠폰 이력 조회 → 유효기간 내 재발행 가능
- 환불 시 쿠폰 재발행 요청: 유효기간 확인 후 처리

### 예외 처리 (팀장 승인 필요)
- 유효기간 만료 쿠폰 재발행
- 중복 쿠폰 적용 허용 요청
- 이미 소멸된 포인트 복구
