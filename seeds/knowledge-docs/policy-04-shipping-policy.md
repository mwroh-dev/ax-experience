# 스타일커머스 배송 정책

**버전**: v3.0 | **시행일**: 2024년 1월 1일

---

## 1. 배송 유형

### 1.1 일반 배송
- **배송비**: 기본 3,000원 (조건 충족 시 무료)
- **배송 기간**: 결제 완료 후 1~3 영업일 출고, 출고 후 1~2일 도착
- **도착 예상**: 총 3~5 영업일
- **담당 택배사**: CJ대한통운 (기본), 한진택배, 로젠택배 (상품/지역별 배정)

### 1.2 당일/익일 배송 (로켓배송)
- **대상 지역**: 서울, 경기 일부 (서비스 지역 지속 확대 중)
- **당일 배송**: 오전 11시 이전 결제 시 당일 도착
- **익일 배송**: 오전 11시 이후 결제 시 익일 도착
- **배송비**: 무료 (멤버십 조건 없음, 단 최소 주문금액 15,000원)
- **로켓배송 마크** 상품에만 적용

### 1.3 설치 배송
- **대상**: 가구, 대형 가전, 운동기구 등
- **배송 기간**: 결제 후 7~14 영업일
- **설치비**: 상품별 별도 안내 (3만 원~15만 원)
- **일정 확정**: 담당 기사 직접 연락하여 일정 협의

### 1.4 해외 직구 배송
- **배송 기간**: 결제 후 10~20 영업일 (통관 기간 포함)
- **배송비**: 상품별 별도 (주문 시 표시)
- **통관 지연**: 세관 검사 시 5~10일 추가 소요 가능
- **관부가세**: 150달러 초과 시 소비자 부담

## 2. 무료배송 기준

### 2.1 기본 무료배송 기준

| 조건 | 배송비 |
|------|--------|
| 주문금액 50,000원 이상 | 무료 |
| 주문금액 50,000원 미만 | 3,000원 |
| 멤버십 Basic 이상 가입 | 30,000원 이상 시 무료 |
| 멤버십 Premium 가입 | 모든 주문 무료 |

### 2.2 무료배송 예외 (추가 배송비 발생)
- 도서산간 지역 (아래 별도 안내)
- 당일 배송 선택 시 (Premium 멤버십은 무료)
- 설치 상품의 설치비 (배송비 별도)
- 해외 직구 상품

### 2.3 무료배송 기준 하락 시

일부 환불 처리 후 잔여 주문금액이 무료배송 기준 이하로 떨어지는 경우:
- 배송비 3,000원을 환불 금액에서 차감
- 단, 상품 하자로 인한 반품의 경우 배송비 차감 없음

## 3. 도서산간 추가 배송비

### 3.1 추가 배송비 기준

| 지역 | 추가 배송비 |
|------|-----------|
| 제주도 | 3,000원 |
| 제주도 외 도서 지역 | 5,000원~8,000원 |
| 울릉도/독도 | 15,000원 |
| 산간 지역 (우체국 준용 지역) | 3,000원 |

### 3.2 도서산간 지역 배송 제한
다음 상품은 도서산간 지역 배송이 불가합니다:
- 대형 가전 (설치 서비스 제공 불가 지역)
- 냉장/냉동 식품 (신선도 유지 불가)
- 무거운 가구 (80kg 이상)

### 3.3 도서산간 배송 기간
도서산간 지역은 일반 배송 기간에 2~5일이 추가로 소요됩니다.

## 4. 출고 기준일 및 배송 기한

### 4.1 출고 기준일 계산

**결제 완료 시점 기준**:
- 오후 2시 이전 결제: 당일 출고 가능
- 오후 2시 이후 결제: 익일 출고 (다음 영업일)
- 공휴일/주말 결제: 다음 영업일 출고

**예시**:
- 월요일 오전 10시 결제 → 월요일 출고 → 화~수요일 도착
- 금요일 오후 3시 결제 → 월요일 출고 → 화~수요일 도착

### 4.2 출고 지연 사유

다음 경우 출고가 지연될 수 있습니다:
- 재고 부족으로 인한 입고 대기
- 국가 공휴일 (설날 연휴, 추석 연휴 등)
- 물류센터 자체 재고 실사 기간 (연 2회, 사전 공지)
- 기상 악화 (태풍, 폭설 등)

출고 지연 예상 시 SMS/앱 알림으로 사전 안내.

## 5. 배송 추적

- **운송장 발급**: 출고 완료 즉시 SMS 발송
- **추적 방법**: 앱 내 주문내역 > 배송 추적 또는 택배사 사이트 직접 조회
- **업데이트 주기**: 배송 상태 변경 시 자동 업데이트 (수 시간 단위)
